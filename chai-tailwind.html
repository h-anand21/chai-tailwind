v1.0.0 — Utility-First CSS Engine

ChaiTailwind

A lightweight, zero-dependency CSS utility engine. Writechai-* classes in your HTML — the engine parses them at runtime and applies inline styles.

<div class="chai-flex chai-gap-4 chai-p-6 chai-bg-blue-100 chai-rounded-xl">
  <button class="chai-bg-blue-600 chai-text-white chai-px-4 chai-py-2 chai-rounded-lg chai-font-semibold">Click</button>
</div>
Edit the HTML on the left, then click Run (or Ctrl+Enter)
